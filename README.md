# Loto M1 (web)

Versiunea web a aplicației Flutter `loto_m1_app`: predicție didactică prin telescopare (M1 și Tandem 3).
Pe iPhone: deschide pagina în Safari → Partajare → „Adaugă pe ecranul principal”.

Extragerile sunt independente; aplicația are scop didactic și nu oferă pronosticuri garantate.
